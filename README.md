# Olist E-Commerce

Olist es una empresa brasileña de comercio electrónico que funciona como una plataforma que conecta vendedores con clientes para facilitar la venta de productos por Internet.

## Información
El presente análisis se realiza utilizando únicamente el dataset público de Olist E-Commerce disponible para este proyecto.

> Las preguntas, objetivos, análisis planteados, resultados, conclusiones y recomendaciones obtenidos se limitan exclusivamente a la información disponible de los datasets y no deben interpretarse como una evaluación del desempeño actual de Olist.
#

### Objetivo
Analizar el desempeño comercial y operativo de Olist utilizando el dataset público disponible, con el fin de identificar patrones, tendencias y oportunidades de mejora en ventas, productos, clientes, vendedores, entregas y satisfacción del cliente.
